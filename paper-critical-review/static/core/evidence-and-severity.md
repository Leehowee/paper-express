# 证据、严重程度与优先级

## 三种判断分开记录

1. **科学有效性**：论证是否成立，证据能否支持结论。
2. **贡献价值**：相对已有知识推进了什么，对谁有用。
3. **目标适配度**：贡献类型、读者和呈现是否适合指定 venue。

判断不依赖作者名望、机构、既有论文发表地点或是否使用流行技术。不将“不是我偏好的研究路线”写成技术缺陷。不默认给总分；用户要求模拟正式评分时，先取得相应年份的评分定义，并逐项给出依据和不确定性。

## 主张状态

| 状态 | 含义 |
| --- | --- |
| `supported` | 已见证据足以支持明确条件下的这条主张；不是对整篇论文的认证 |
| `partial` | 支持部分条件、较弱结论或某些实例 |
| `unsupported` | 已核对的论证尚不能建立所述结论，未有有效反例 |
| `refuted` | 存在核实的反例、逻辑矛盾或直接相反的适用证据 |
| `not_assessable` | 材料或必要语义不足，暂不能判断 |

区分未提供附件与附件本身没有证明。全文未检查时，只能说明“本次提供的材料未见”。一个核心报告要素在应完整的稿件中确实缺失，可以形成报告完整性问题；这不等于相关实验事实上没有做。

## 问题分级

| 严重程度 | 是否阻断 | 使用条件 |
| --- | --- | --- |
| `major` | `true` | 当前核心结论不能成立，或关键证据不可解释，必须修复或收缩主张后才能建立作者的主要论证 |
| `major` | `false` | 重要的贡献区分、适用范围或证据环节受损，但尚不独立推翻整个核心论证 |
| `minor` | `false` | 局部信息、标记或表述问题，修复不改变核心解释 |

`blocking` 指当前核心主张受阻，不是编辑退稿决定。图表问题、表述歧义或缺失参数都可能影响核心推断，不能按形式自动降为 minor。相反，昂贵的补充实验也可能只是可选增强。

每条分级附一句影响理由。证据不完整、检查尚未完成、未公布代码，均不自动等于 major 或 blocking。对重要性或目标适配的不足，说明差距；不要把它伪装成数学或实验错误。

## 修改优先级

- **P0**：先解决阻断核心主张的问题。允许多条并列；若无则不设。
- **P1**：解决其他重要问题，使结论边界、贡献和关键比较可靠。
- **P2**：解决不改变核心推断的局部问题。
- **Optional**：可增加价值，但不是现有主张成立的必要条件。

优先级表示影响与依赖，不表示耗时。工作量、计算成本和可用资源另记；资源不足时给出缩小问题或收缩主张的方案，不能虚构完成结果。Optional 不进入必须关闭的问题计数。

## 意见的最小证据单元

`issue_id → claim_id → claim_location → evidence_location → observation → inference → severity_rationale → action → closure_test`

定位状态使用 `located`、`location_missing` 或 `not_assessable`。没有页码时可以使用真实章节及唯一短摘录；找不到准确位置则如实标记。将“原稿事实”“本次计算”“推断”“作者待说明事项”分别写明。

不设 major/minor 数量下限，不制造多审稿人共识，不把问题数量当作论文质量分数。正面判断同样应注明依据；如果当前材料未发现重大缺陷，直接报告这一结果及检查范围。
