# 图表与内部一致性审查

先核对图表表达了什么，再评价它是否美观。图表来源和正文解释共同决定问题的影响。

## 图表检查

| 对象 | 核对内容 |
| --- | --- |
| 动机图 | 实测还是示意；条件、样本选择及现象是否足以引出问题 |
| 路线与流程图 | 比较是否同一层级；信息、监督和计算预算是否对称；箭头与算法一致 |
| 主结果表 | 指标方向、单位、聚合、缺失符号、加粗规则及来源 |
| 消融图表 | 变体定义、其他条件、交互与成本变化 |
| 机制与投影 | 色标、归一化、投影配置、定量对应及因果措辞 |
| 参数与过程 | 横轴实际数值与刻度、选择规则、失败区间；目标与任务指标的区分 |
| 效率图 | 资源单位、计时范围、预算含义和性能代价 |
| 案例 | 来源、筛选规则、整体覆盖、失败情形；模型解释与真值的区别 |

字体和颜色只在影响阅读、数据识别或推断时形成具体意见。可以引用图中实际面板位置，不编造数据来源。

## 数值与文字回算

在口径明确时核对百分比与百分点、绝对与相对提升、比值与对数、平均数与加权数、排名、指标边界和正文宣称的胜出范围。计算保留单位、方向、输入位置和允许的舍入范围。

口径未知时，先列出可能解释及需要的定义。由已舍入分项算出的细小差异不立即判错。表格列平均与逐样本平均可以不同，不能在未核对定义前认定矛盾。

发现相同图像、重复数值、整齐误差条或异常分布时，记录可观察的具体事实，提出原图、日志、运行标识或数据出处核验。它们可能来自共享数据、确定性流程、舍入或制表错误，单独不足以证明造假。

## 审计状态

- `confirmed_internal_error`：定义及材料充分，已能复核具体矛盾。
- `aggregation_ambiguity`：不同合理聚合产生不同解释，需澄清口径。
- `provenance_gap`：数值或图像来源无法对应到可检查记录。
- `suspected_duplication`：发现具体重复迹象，原因尚未确认。
- `unresolved_input_needed`：需要指定原始材料才能判断。
- `not_assessable`：当前材料无法开展此项检查。
- `passed`：所列范围内未发现问题，不代表整篇数据认证。

每项附检查范围和依据。审计发现需要进入修改清单时，按它对主张的影响确定严重程度；不得把所有审计异常升级为 blocking。独立小组模式下的后续统一审计单独署明，不回填成审稿人共同发现。

## 修改建议的边界

图表模块可修正编码、标记、来源链接、制表或绘图代码；数据与协议有问题时必须先纠正研究记录或补充分析。改变坐标、选择案例或删除不利条件不能充当证据修复。
