# CCF-A 会议视角

CCF-A 是分类范围，不是共用评审表。选择具体会议、年份、track 和论文类型，按适用规则审查。ICLR、ICML 等公开指南提供的启发见 [来源依据](../../references/source-basis.md)，不外推为所有会议的政策。

## 检查顺序

1. 提取正文读者能记住的新知识：它回答哪个问题，为什么需要这个设计或分析，关键证据是什么。
2. 区分创新、技术成立与意义。使用已有组件、没有榜单第一或没有新增理论，均不自动否定贡献；需要检查组合、发现、条件放宽或任务改变是否产生新知识。
3. 检查最关键对比是否匹配信息与预算，决定性结果是否足够支撑主张。把对录用判断重要的问题与有益但不必要的扩展分开。
4. 检查正文是否说明核心假设、方法和关键结果，附录是否提供必要证明及配置。已经在附件提供的内容应实际查看后评价；正文可用简洁提示保持论证可理解。
5. 版面紧张可通过重组解决，不能作为隐藏失败条件或关键前提的理由。缺少次要细节与缺少可判定的核心依据分开处理。
