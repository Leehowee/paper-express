# 从已有论文阅读记录提炼的审查问题

这些条目复用前四部分的专题阅读，不是新一轮对作者论文的正式评审，也不根据作者或发表 venue 预设结论正确。编号和物理页码可在 [图表来源索引](../../paper-figures-tables/references/source-index.md) 及 [理论来源索引](../../paper-theory/references/source-index.md) 中追溯。

| 阅读记录中的观察 | 迁移到新稿的审查问题 | 相关模块 |
| --- | --- | --- |
| GH03，p.1 Fig.1：注意力诊断与任务结果并置 | 内部现象与任务效果的共现是否被误写为因果？需要干预还是只需准确解释？ | 机制与统计审查 |
| GH05，pp.2、4 Fig.1–2：结果随预算可能反转 | 摘要是否只使用有利预算点？结论能否覆盖已测区间与任务？ | 适用边界、图表审查 |
| XP02，pp.8、10：部分成绩按多次运行中的最佳值报告 | 比较是否匹配聚合规则？不能把最佳值当均值，也不能从中制造 SD | 实验与统计审查 |
| XP06，pp.31–32：案例包含改善与恶化 | 筛选是否透明？模型生成解释是否被当作真实原因？ | 案例与机制审查 |
| XP07，pp.17–18：组件收益随条件改变 | “所有模块始终有效”的表述是否忽略干净条件或反向结果？ | 消融与范围审查 |
| XL02，pp.11–12：内部补全质量与下游效果分开，近似变体不保证目标单调 | 内部代理指标是否足以证明任务改善？经验停止是否被提升为优化保证？ | 理论与实验对齐 |
| XL03，p.8 Table 1；XL09，p.7 Table 2：粗体带有统计比较含义 | 数值最优、未检出差异与等效性是否混淆？原始定义是否保留？ | 统计与表格审查 |
| XL07，pp.10–11：成本的对数和相对表达需结合定义理解 | 对数差、比值、速度倍数是否被错误转换？ | 一致性审计 |
| XL08，pp.7–9：目标与求解器的交叉消融，主表保留不利结果 | 新目标与新求解的贡献是否能分离？是否保留了非胜出情况？ | 消融、系统证据 |
| XL08/XL06/XL09 理论专题：不同优化对象与应用条件需要分别核对 | 子问题、值函数、原问题与最终输出的保证是否被混用？ | 理论与 Lean 审查 |

以上问题是迁移后的通用审查维度，并不意味着每篇新稿需要相同图表、相同实验数量或相同证明技术。详细观察见 [Gao Huang](../../paper-figures-tables/references/gaohuang-analysis.md)、[Xi Peng](../../paper-figures-tables/references/xipeng-analysis.md)、[Xinwang Liu](../../paper-figures-tables/references/xinwangliu-analysis.md) 与 [独作论文理论分析](../../paper-theory/references/solo-paper-theory.md)。
