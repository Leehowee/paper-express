# 投稿约束与内容分配

## 先明确适用规则

记录目标 venue、年份、稿件类型、投稿阶段、单双栏、正文页数或字数、摘要限制、参考文献是否计入、附录与补充材料形式，以及官方来源和核查日期。实际格式要求以相应版本官方说明为准。

未提供目标或无法核实时，允许先完成结构与正文草稿，将格式状态记为待确认。不得从样本 PDF 的页数反推投稿限制，也不将某届 AAAI、ICLR 的限制写成固定配置。CCF 类别用于路线命名，不代替核实目标会议及当前投稿要求。

## 依据论证作用安排位置

| 内容作用 | Trans 默认安排 | 会议默认安排 |
| --- | --- | --- |
| 核心问题与贡献 | 正文，充分界定条件与已有工作 | 正文，尽早清楚地给出 |
| 核心方法与关键假设 | 正文，展开设计依据与推导 | 正文，给出足够定义、目标与操作 |
| 决定性理论 | 正文命题、条件与必要证明 | 正文命题、条件与关键思路；长证明按规则入附录 |
| 主结果与关键控制 | 正文，系统解释主要差异 | 正文，保留决定贡献是否成立的比较 |
| 改变结论的失败与代价 | 正文明确呈现 | 正文明确呈现，细节可补充 |
| 配置与复现信息 | Methods/Experiments 中有组织地展开 | 正文保留影响比较的设置，完整配置入附录或规定载体 |
| 次要推导、额外指标和扩展案例 | 有解释作用则保留；去掉无信息重复 | 附录，提供准确引用与目的 |

该表是作者组织偏好，不是所有刊会的官方规则。Trans 默认不依赖附录；若真实限制无法容纳必要证据，先删冗余、整合图表，仍不够时明确呈现篇幅冲突，依据用户选择和目标规则启用补充材料或缩小论文范围。

## 分配与压缩流程

1. 列出正文必须完成的判断：问题真实、贡献有差异、方法可理解、证据充分、边界可见。
2. 为各节和关键浮动体分配可调整预算，并留出排版余量。不要按固定百分比覆盖所有论文。
3. 优先删去重复背景、逐行复述表格和无信息的过渡；再合并近似分析或转移完整细节。
4. 每次迁移写明去向与正文保留的摘要。关键假设、决定性消融或负面证据不能因被称作“补充分析”就被移走。
5. 用实际目标模板编译后检查总页数和可读性。调整内容与图表结构，不靠擅改页边距、字号或行距满足限制。

会议正文可独立判断，附录可供深入核查；若正文主张完全依赖附录中首次出现的前提、方法或对照，就需要重新分配。
