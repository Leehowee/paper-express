# 论证路径

按研究真正建立的贡献选择路径。路径决定论证如何展开，不决定论文应当声称什么。下面几种安排可以跨期刊和会议使用，再按相应路线调整展开程度。

## 问题与假设限制驱动

适用于已有方法依赖某个条件，而目标场景不满足该条件的研究。

从任务和已有成功出发，明确关键假设及其失效情形，区分新问题与最接近的问题，解释为什么直接迁移现有方法不足。方法逐项回应这些困难；实验分别检查原有条件、目标条件和更困难的边界。

论证骨架：`任务需要 [能力] → 现有路线依赖 [条件] → [证据] 显示该条件在 [范围] 不成立 → 研究 [明确问题] → [设计] 回应 [障碍] → [验证] 确立 [结论与边界]`。

## 理论与优化驱动

适用于目标函数、可识别性、优化性质、复杂度或理论关系构成主要贡献的研究。

从已知定义与结论出发，指出未被覆盖的条件或求解障碍，形成命题和设计目标。方法按必要定义、目标变换、关键命题、求解过程和适用范围展开。验证关注理论条件与实现是否相符，以及理论改变是否带来目标任务所需的收益。

论证骨架：`已有结论限于 [条件] → 需要回答 [数学问题] → 建立 [命题] → 得到 [算法或认识] → 在 [设置] 检验实现与实际作用`。

有公式不意味着理论驱动。若理论仅解释一个组件，应作为局部支撑，不取代实际主要贡献。

## 现象与假说驱动

适用于反常观察或机制假说引出研究的工作。

先呈现可重复的现象，说明现有解释的不足，再提出有竞争解释的假说。方法是检验或利用假说的手段；实验优先展示能够区分解释的对照，再报告应用效果。观察、解释和机制结论分别校准强度。

论证骨架：`观察到 [现象] → [已有解释] 尚不能说明 [关系] → 假设 [机制] → 设计 [区分性检验] → 证据支持 [有限结论]`。

## 统一框架与推广驱动

适用于多个方法可由共同对象、目标或推断过程描述的研究。

指出现有路线的共同结构与缺失联系，定义统一对象，列明哪些特例可以精确恢复、哪些只是近似或启发式联系。选择具有不同作用的实例检验框架，避免仅改名重述已有方法。

论证骨架：`多条路线共享 [结构] → 缺少 [统一关系] → 定义 [框架] → 在 [条件] 得到 [特例/新实例] → [理论与实验] 检查覆盖范围和新增价值`。

## 选择与切换

一个主路径通常足够，必要时用另一条路径支撑关键环节。证据改变后调整主线：假说未获支持就收缩机制结论；定理条件过强就如实缩小理论覆盖；泛化范围有限就限定框架适用场景。不要通过更换术语保留已失去依据的强主张。
