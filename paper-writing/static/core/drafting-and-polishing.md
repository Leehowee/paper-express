# 直接起草与润色

## 按输入选择工作方式

- 用户给研究笔记、公式、结果或图表并要求写作：加载当前路线与章节的 `assets/templates/` 文件，选择合适套路，直接生成连贯初稿。
- 用户给已有段落并要求润色：保留事实、符号、引用和证据强度，使用该节的润色模式重写。原结构合理时只修语言，不为了套模板重排全文。
- 用户要求结构重写或原文逻辑明显断裂：先选择段落套路，将已有信息重新组织成稿，再简要解释变化。
- 用户只要建议或大纲：按其要求交付；其余写作任务以实际正文为主要产物。

初稿不是句型清单，润色不是修改建议列表。返回已经完成填充和衔接的文字；将确实缺失的研究信息另行指出。

先辨认用户要的是工作初稿还是可提交正文。工作初稿允许精确的待补标记，并把候选机制和实验计划保留为相应语气；可提交正文仅使用已建立事实。尚缺决定性证据时仍交付可完成的段落，同时指出具体未达成项，不将研究计划改写成已完成研究。单次或初步结果可以据实写入，不自动升级为稳定提升。

## 怎样使用可填充模板

`{{FIELD}}` 表示需要从用户材料中提取的具体内容，字段名采用大写字母与下划线。字段可以是一组名词、一个分句、一条公式或一段结果解释，按所在句子的语法填入。填充后重新检查冠词、单复数、时态、指代和逻辑连接，不做机械字符串替换。

同一研究对象在全文保持一致。例如 `{{TASK}}` 是同一研究任务，`{{METHOD}}` 是同一方法名；具体组件、公式和实验分别使用可辨认的名称。`{{LOCAL_DEFINITIONS}}`、`{{RESULT}}` 等局部字段按当前公式或实验取值，不能跨段机械复用。`{{CITATIONS}}` 只能填入已核实引用，结果字段只能填入已有结果，`{{THEORY_RESULT}}` 只能填入与证明状态匹配的命题。

| 常用字段 | 应填内容 | 避免填入 |
| --- | --- | --- |
| `{{TASK}}` / `{{SETTING}}` | 任务及目标条件 | 一个宽泛领域名代替问题 |
| `{{ASSUMPTION}}` / `{{GAP}}` | 现有方法的具体条件或未解决关系 | “性能不好”“研究不足” |
| `{{KEY_IDEA}}` | 最核心的建模或设计变化 | 方法名或模块清单 |
| `{{OPERATION}}` | 实际执行的操作、输入与输出 | “增强”“优化”等未解释动作 |
| `{{EVIDENCE}}` / `{{RESULT}}` | 证据位置、事实、比较对象和范围 | 想达到的效果或未做实验 |
| `{{ASSUMPTIONS}}` / `{{THEORY_RESULT}}` | 命题前提及精确结论 | 从曲线推断的全局保证 |
| `{{BOUNDARY}}` | 影响结论的条件、例外或代价 | 没有依据的泛化承诺 |

模板中的其他字段按名称和上下文从材料取值。遇到歧义，在作者说明中标注解释，不为了填满每个槽位发出冗长问卷。

## 段落选用规则

每个资产文件包含整段英文模板及中文用途说明。标题中的“段 1”“套路 A”“可选”是作者导航，不进入论文。通常选一套主套路，再按研究需要加入局部模块，不把所有变体拼成一节。

可选理论段需要真实理论内容，可选结果段需要真实结果；没有这些材料就省略或明确保留待补位置。模板里 `We show`、`We prove`、`This supports` 等词也受证据约束，不因它们已写在模板中就默认成立。

仅在影响当前论点时写入边界、例外或未解决事项，不让每段都以重复的限制句结尾。模板中的多个操作、目标项、贡献或研究问题均可按真实内容增减。

图表、公式和附录先使用稳定标签，如 `{{MAIN_TABLE}}`、`{{OBJECTIVE_EQ}}`、`{{PROOF_SECTION}}`，再与稿件已有编号对应。尚未生成的对象可以保留明确待补标签，不能编造 Table 1 或 Appendix A 来暗示对象已经存在。理论与图表继续沿用各自接口。

## 初稿的实际生成

从材料提取“问题—差异—操作—证据—边界”，选定套路后直接写段落。只在材料支持时补充连接句。结果缺失时：

- 能写的背景、定义、设计和算法先写完。
- 必须依赖缺失证据的地方用 `[待补：具体结果或证明]`。
- 已知没有结果且用户接受无结果草稿时，省略经验结论句；不要把正文全部改成研究计划。
- 区分材料没有说明与方法实际不存在，不能将信息缺失自动写成研究局限。

## 润色的实际改写

先锁定原文中的事实、数值、比较范围、引用、符号和限制，再处理句法与段落关系。分别修复空泛背景、模块堆叠、公式突然出现、结果逐行复述、过强机制推断和全文重复。每节模板中的“润色前→润色后”展示可直接迁移的改写方式。

示例中“补充材料”是改写所需的已知输入，不是模型可以自行添加的事实。没有这些输入时，返回更保守但可用的版本，或保留精确待补位置。保留作者原意与已知负面结果；需要改变结论时说明原因。

## 输出形式

先给完整初稿或润色稿，再用少量条目说明关键调整和待补内容。用户要求逐句对照时才附原句—改句表；用户要求模板本身时保留字段。中文任务沿用相同段落逻辑写成自然中文，不强制输出英语。

交付正文前移除作者导航和模板引用块格式，检查是否仍残留 `{{FIELD}}` 等未填字段。能够填写的内容写完整，必要缺口统一改为明确待补标记；图表、章节和公式引用与实际稿件一致。
