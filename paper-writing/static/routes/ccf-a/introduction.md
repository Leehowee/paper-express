# CCF-A：Introduction

直接起草或润色时，使用 [成段模板与改写示例](../../../assets/templates/ccf-a/introduction.md)。下文用于判断章节内容、证据与完成要求。

## 章节任务

尽早建立清楚的问题与关键洞见，让读者理解为什么需要这项工作、为什么直接方案不足，以及本文如何提供可验证的进展。

## 必要输入

具体任务、限制或现象、最近工作、核心设计与决定性结果。引言中的示例、统计或诊断实验需要实际来源。

## 段落推进

1. **对象与矛盾**：简要说明已有能力及其依赖条件，将目标问题尽早带入。
2. **具体问题**：用简洁定义、真实示例或诊断结果说明条件为何不足，并区分最接近的相邻问题。
3. **解决障碍**：解释直接替代或已有路线为什么不能充分回答问题，只保留对本文设计有作用的障碍。
4. **关键洞见**：先写一个能概括核心变化的句子，再解释必要组件如何实现它。
5. **贡献与证据**：归纳实质新增内容及最重要的验证，说明范围。

这些是段落职责，可合并或展开。理论工作可用数学缺口代替经验失效现象；统一框架工作可用共同结构及缺失联系进入。不要为了符合问题驱动套路而编造真实场景或动机实验。

## 可改写骨架

> The central difficulty is [精确障碍]. Existing [最近路线] addresses [已有能力], but assumes [影响目标问题的条件]. Our key idea is to [核心变化]. This leads to [方法原则], which handles [障碍] through [必要操作]. We test this claim using [决定性验证].

贡献列表可用也可不用。使用时，每条应说明新增事实、关系或能力，并能对应后文位置。实验验证通常是支持贡献的证据，不因实验很多就自动成为独立创新。

## 图表与篇幅

引言图优先完成一项作用：展示限制、区分问题或比较路线。按 [图表接口](../../../interfaces/figures-tables.md) 提供主张与来源。图中已清楚表达的枚举不再在文字里完整重复。

较长文献综述和方法推导放入相应章节或允许的附录。最近工作差异、核心问题定义和重要边界应留在正文。

## 完成检查

读者在阅读方法前能复述研究问题和关键想法。每个问题类别对应实际方法或验证；训练与测试条件没有在动机和实验之间变化；没有用“无人研究”替代具体比较。
