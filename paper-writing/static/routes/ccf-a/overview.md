# CCF-A 会议路线

在有限正文中建立一条清楚且充分的论证，使读者能够判断研究问题、方法差异、主要证据和适用边界。附录提供核查深度，正文承担核心贡献的说明责任。

## 先确定正文必须回答的问题

1. 为什么现有认识或方法不足以处理目标问题？
2. 本文改变了哪一个关键设计、假设或理论关系？
3. 方法怎样运行，依赖哪些信息与条件？
4. 哪些比较足以支持主要贡献，哪些结果限制了结论？

以这些问题安排篇幅和图表，再根据目标年份与阶段的规则调整。不要用固定页数或固定章节比例替代内容判断。

## 正文与附录

| 正文保留 | 附录承接 |
| --- | --- |
| 问题定义、最近工作差异和重要性依据 | 更广的文献背景与补充比较 |
| 核心算法、关键目标、假设及训练/推理关系 | 详细推导、长证明、完整伪代码与配置 |
| 主要结论、决定性对照及结论边界 | 扩展数据集、完整参数扫描、额外诊断和案例 |

按作用判断内容位置。某个消融若决定创新是否成立，应在正文中可见；某个证明若包含主要理论创新，正文应呈现其关键步骤。不能一律把 Related Work、所有证明或所有消融移入附录。

## 章节安排

常见结构为 Abstract、Introduction、Related Work、Methods、Experiments、Conclusion 与 Appendix。Related Work 可压缩整合到引言，但最近工作的定位仍保留；Limitations、Impact 等内容按目标要求与实际需要设置。

按需加载 [摘要](abstract.md)、[引言](introduction.md)、[相关工作](related-work.md)、[方法](methods.md)、[实验](experiments.md)、[结论](conclusion.md)、[附录](appendix.md)。不要将期刊稿简单截短：先重建正文证据顺序，再组织可定位的补充层。

实际写作同时加载该节链接的成段模板。引言提供问题、理论、统一框架和现象—假说等套路；方法模板把核心操作与必要条件写进正文；附录模板承接完整推导和配置。润色时使用压缩与重组示例，保留影响结论的限定和证据。
