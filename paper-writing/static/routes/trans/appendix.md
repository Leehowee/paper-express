# Trans：条件附录与补充材料

直接起草或润色时，使用 [成段模板与改写示例](../../../assets/templates/trans/appendix.md)。下文用于判断章节内容、证据与完成要求。

## 启用条件

本路线默认在正文中完成主要论证。只有用户采用补充材料且目标期刊与稿件类型允许时，才将内容移入附录或独立补充文件。不要因样本论文使用过补充材料，就自动改变当前稿件的安排。

未启用时，本模板用于检查正文完整性并分配较长推导、配置与扩展分析，不生成空附录，也不留下“详见附录”的失效指引。

## 必要输入

已核实的投稿规则、正文主线、待补充内容、相关命题和图表编号、正文引用位置。

## 启用后的组织

按正文问题组织补充内容，可以依次包括完整推导、扩展实现、完整实验结果、额外案例与复现信息。每节先说明它补充正文的哪个判断，再呈现材料。

对证明，重述同一命题与假设，给出完整步骤及依赖；对实验，说明新增设置、与正文的差异、结果及其解释；对配置，给出可执行或可复用的具体值与版本。重复信息使用准确交叉引用。

正文保留决定结论的前提、主要命题、关键证据和重要失败。若补充结果改变了核心解释，需要先改正文，而非只在补充材料中补一句限制。

## 可改写开头

> This section provides [证明/配置/扩展结果] for [正文位置]. It examines [目的] under [条件], using the same [定义或协议] as the main text except for [明确差异].

## 接口与完成检查

沿用 [理论接口](../../../interfaces/theory.md) 和 [图表接口](../../../interfaces/figures-tables.md) 的命题与图表编号。Lean 文件及运行记录应有真实位置，不能由一段证明文字代替。附录格式、独立文件要求与引用方式按目标说明核实。

检查所有正文引用可达，补充材料不出现未交代的新方法或相互矛盾的配置。正文可以建立核心结论，补充材料能够支持深入复核。
