# 图表模块接口

## 用途与调用条件

把图表作为论证的一部分：先确定它回答什么问题，再选择展示形式。可由 Introduction、Methods、Experiments、Appendix 调用，也可由用户直接提供数据、流程或现有图表独立使用。

图表模块 [paper-figures-tables](../../paper-figures-tables/SKILL.md) 已实现。按其 [模板目录](../../paper-figures-tables/assets/template-catalog.md) 选择绘图配置、表格或可编辑 PPTX/SVG；使用 [请求与返回格式](../../paper-figures-tables/interfaces/writing.md) 传递上下文。已有图表可直接审查并复用，不必重新制作。未找到运行环境或材料不足时，交付可完成的结构与明确待补项，不声称已生成或核查依赖该环境的产物。

## 按作用选择

| 图表作用 | 需要传递的内容 |
| --- | --- |
| 引言动机实验图 | 现象、诊断协议、比较条件、原始结果与支持范围 |
| 路线对比图 | 各路线真实假设、输入输出、共同坐标及区别；可选 |
| 方法流程图 | 输入、变量、模块、信息流、训练/推理路径与公式对应 |
| 主结果表 | 方法、任务、协议分组、指标、数值及不确定性 |
| 消融图或表 | 变体含义、控制因素、资源匹配和变化量 |
| 参数与稳健性分析 | 参数或条件范围、默认值、选择方式与全部相关结果 |
| 效率与代价图表 | 资源、单位、计时范围、硬件与成本口径 |
| 案例与失败展示 | 原始样本、结果来源、选择方法及代表性限制 |

图与表按信息需要选择。精确数值比较常适合表，趋势或权衡常适合图；同一证据不必重复制作两种形式。

## 请求信息

| 字段 | 内容 |
| --- | --- |
| `request_id` / `claim_ids` | 图表稳定编号与关联主张 |
| `section` / `purpose` | 所在章节、要回答的问题和预期读者判断 |
| `content_kind` | 实测数据、模型输出、概念示意或其明确分区 |
| `sources` | 数据、代码、日志、方法定义或原图的真实位置和版本 |
| `data_semantics` | 行列含义、单位、指标方向、统计单位、重复次数、误差定义 |
| `comparison_protocol` | 划分、资源、监督、参数选择与不可直接比较的分组 |
| `design_content` | 需要的面板、流程节点、表格列、对照或案例 |
| `layout` | venue、单双栏、正文/附录、可用尺寸与阅读顺序 |
| `outputs` | 需要的文件格式、可编辑源文件或代码、图注与标签 |
| `known_limits` | 缺失值、失败、未完成分析和不可外推的结论 |

```yaml
request_id: TB1
claim_ids: [C1]
section: experiments
purpose: "比较目标条件下的主要任务效果"
content_kind: measured
sources: []
data_semantics:
  metrics: []
  independent_unit: null
  repeats: null
  uncertainty: null
comparison_protocol: null
layout:
  location: main_text
  columns: null
outputs: [editable_source, publication_asset, caption, stable_label]
```

数据缺失时，可以设计表头、面板或图注结构，但不得填入虚构数值、误差条或看似实测的曲线。概念图也应忠实于实际方法；以示意箭头表达的机制不能自动视为已经验证。

## 返回信息

- 图表文件、可编辑源文件或生成代码的真实位置，格式与尺寸。
- 稳定标签、图注或表注，以及对应的正文引用建议。
- 数据与展示的对应关系，包括聚合、归一化、筛选、坐标变换和缺失值处理。
- 核查状态：`layout_only`、`generated`、`checked_with_limits` 或 `checked`，及实际完成的检查。
- 数据检查和视觉检查分别报告，注明存在的限制或待补项。

图注交代展示对象、面板、关键设置、指标、单位、缩写及误差含义，使图表能被独立理解。正文负责解释它对主张意味着什么，避免逐项重复图注。

## 写作方接收规则

1. 将每个图表结论对应到真实数据或方法定义，核对百分比、排序、最优标记和缺失值。
2. 核对比较条件、指标方向、误差来源及独立重复单位。没有原始重复数据时不能推造显著性或置信区间。
3. 检查图中变量、组件、箭头和公式与正文一致，特别是冻结/更新、训练/推理和可用监督的差异。
4. 确认案例选择、截取区域、坐标范围和聚合方式没有改变结论含义；重要失败与不确定性可见。
5. 按最终尺寸检查文字、线条、颜色、表格密度和面板顺序。正文与附录可调整细节量，但保持术语和数据口径。
6. 核对正文、图注、标签与附录引用，新增限制同步回写相关主张。

图表经过渲染不等于数据经过验证，视觉清楚也不等于结论成立。状态应精确到实际完成的工作。

## 独立调用

独立任务沿用相同格式，可以暂不指定论文路线或章节。先明确展示目的、已有数据或方法结构和需要的输出；无全文时仍可制作或审查一张图表。若缺少决定图表含义的输入，完成可独立确定的布局，并保留依赖该输入的内容。
