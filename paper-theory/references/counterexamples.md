# 反例与条件检查

反例用于定位某条一般推理失效的原因。只有满足待审命题全部前提的反例，才能推翻该命题；不能用更大对象类中的例子直接否定带特殊约束的结论。以下例子由本模块构造，形式化覆盖见 [验证记录](validation.md)。

## 1. 凸不等于唯一最优

令 `f(x)=0`。它在实数或任意非空区间上凸，但 0 和 1 都可为最优点。`constant_has_two_minimizers` 形式化了两个不同最优点的存在；常函数的凸性是这里的解析说明。唯一性需要严格凸性等足够条件或其他专门证明。

## 2. 谱值函数可以凸而不可微

令

```text
K₁ = [[1, 1/2], [1/2, 1]],
K₂ = [[1, -1/2], [-1/2, 1]],
γ = (t, 1-t),  0 ≤ t ≤ 1,  k = 1.
```

两个核都正定且对角为 1。组合 `Kγ=t²K₁+(1-t)²K₂` 的对角元为 `q=t²+(1-t)²`，非对角元为 `t-1/2`。最大特征值为

`J(t)=q+|t-1/2|`。

在 `t=1/2` 处左右导数分别为 −1 与 1，所以 J 不可微。这个例子针对一般半正定核的谱值函数，说明旋转等价不足以保证唯一最优子空间。若研究对象额外要求特定中心化、掩码或数据构造，必须重新检查例子是否仍在允许集合内。本例为解析推导，当前工程未形式化矩阵谱部分。

## 3. 下包络不自动保凸

`g(x)=min{x²,(x-1)²}` 的两个组成函数都凸，但 `g(0)=g(1)=0`，而 `g(1/2)=1/4`，违反凸性中点不等式。`twoWell_not_convex` 形式化了 g 非凸的结论。部分最小化的保凸结果需要相应联合凸性等条件，不能由这一反例否定满足那些条件的定理。

## 4. 包络一阶公式不自动给出二阶公式

令 `F(x,y)=(x-y)²+y²`。唯一最优内层解为 `y*(x)=x/2`，故 `V(x)=F(x,y*(x))=x²/2`，有 `V''(x)=1`。若固定 y 对 F 求二阶偏导则得到 2，两者不同。计算 Hessian 时不能机械沿用一阶包络中的消去方式。本例为解析证明，未列入当前 Lean 入口。

## 5. 单边不等式不能直接平方

取 `a=(0,0)`、`b=(1,2)`，则

```text
(max a - max b)² = 4,
(max(a-b))² = 1.
```

虽然 `max a-max b ≤ max(a-b)`，平方后次序可以反转。适当的控制是 `|max a-max b| ≤ maxᵢ |aᵢ-bᵢ|`。`squared_one_sided_max_bound_fails` 形式化了前一错误平方步骤的数值反例；一般绝对值不等式不在本工程的已验证入口中。

## 6. 正交列数受到维度限制

若 `W∈ℝ^(o×m)` 且 `WᵀW=I_m`，则 `m=rank(WᵀW)≤rank(W)≤o`。因此 `o<m` 时可行集合为空。它是可行性诊断，不否定满足 `o≥m` 的构造。本例为解析推导，未列入当前 Lean 入口。

## 7. 目标值收敛不保证变量收敛

对于恒零目标，令 `x_t=(-1)^t`，目标值恒定而迭代不收敛。也可在 [完整二次示例](worked-example.md) 中取步长 η=2，得到围绕 target 的反射轨迹，目标同样不增而变量一般振荡。当前 Lean 证明了二次更新的下降性质，没有形式化这里的“不收敛”极限命题。

形成候选命题后，优先检查这些低维、边界、重根、零分母和空可行集情形，再投入较大形式化工作。
