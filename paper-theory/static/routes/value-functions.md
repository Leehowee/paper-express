# 值函数与正则性

## 先明确哪个变量被优化

写出 $J(x)=\sup_{y\in Y}F(x,y)$ 或 $V(x)=\inf_{y\in Y}F(x,y)$，记录可行集是否依赖 $x$。使用最大值、最小值或最优解选择函数之前，证明可达性。实数型上确界还需非空性和有界性；不能让 Lean 对空集或无界集合的定义掩盖不存在的最优值。

## 上包络的凸性

在凸集 $S$ 上，若每个 $F(\cdot,y)$ 为凸函数且 $J$ 为有限实值上包络，则对 $a,b\geq0$、$a+b=1$，

\[
F(ax+bx',y)\leq aF(x,y)+bF(x',y)
\leq aJ(x)+bJ(x').
\]

对 $y$ 取上确界得到凸性。可达情形可选取混合点处的最大化解，使用同一不等式；对应 Lean 引理为 `convex_attained_envelope`。

若 $F(x,y)=\sum_p c_p(y)x_p^2$，需先证明 $c_p(y)\geq0$。PSD 矩阵的迹或二次型可以提供这一条件。不要仅因表达式含平方，就忽略负系数或可行域。

## 下包络需要不同条件

分别对每个变量凸，不能推出联合凸，也不能保证最小化掉一个变量后仍凸。若 $F$ 在联合变量上凸，且联合可行集凸，可以通过联合上图集的投影证明值函数凸性；同时处理极值未达到与有限值问题。

不要把“凸函数的逐点最大值凸”直接用于逐点最小值。模板附带 `twoWell_not_convex`，展示两个凸二次函数的最小值可以不凸。

## 可微性与包络公式

先列出实际使用的包络定理：紧性或局部最优解控制、连续性、对外层变量的可微性、可行集是否变化，以及最优解或所有活跃解梯度的一致性。逐项核对引用的定理条件。

在适当正则条件下，唯一内层最优解可支持梯度公式；最优解不唯一时，若所有活跃解给出同一外层梯度，也可能得到可微性。否则优先建立方向导数或次梯度结论，不强行返回一个普通梯度。

谱问题需要区分基旋转的不唯一与截断子空间的不唯一。相关谱隙是常用充分条件之一，不写成所有值函数可微的普遍必要条件。

## 二阶导数需要重新求导

一阶包络公式中未显式出现最优解的导数，不意味着二阶求导时可继续将最优解视为常量。例如 $F(x,y)=(x-y)^2+y^2$，有 $y_*(x)=x/2$、$V(x)=x^2/2$；$V''=1$，而固定 $y$ 求 $F_{xx}=2$。

适用时由隐函数定理推导最优解导数或使用完整 Hessian 公式；无法建立所需正则性时，改用定义、上图集或其他可检查论证证明凸性。

## 算法含义

值函数凸性只描述目标。全局优化保证还需要算法确实求解该目标、正确的导数或次梯度、约束处理、步长及停止条件。内层近似求解时，补充梯度或函数值误差的影响。返回时分别标记函数性质与实际算法保证。
