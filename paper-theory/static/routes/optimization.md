# 优化与收敛

## 从同一个势函数出发

指定每轮比较的目标或势函数 $F$、迭代状态和更新顺序。最小化和最大化混合的嵌套目标，需要先分析值函数或鞍点问题；不能把每个子步骤的改进直接拼成同一方向的总体下降。

## 一步与一轮改进

对乘积可行域上的两块精确最小化，明确写出

\[
F(x^{t+1},y^{t+1})\leq F(x^{t+1},y^t)
\leq F(x^t,y^t).
\]

两个不等式分别来自对应子问题的最优性，且旧解在该子问题中可行。约束耦合时，需要证明所用旧解和新解落在正确的条件可行域。Lean 引理 `two_block_descent` 仅覆盖乘积域中的这一步推理。

近似求解时用实际误差替换精确关系，例如

\[
F(z^{t+1})\leq F(z^t)-cD_t+\varepsilon_t,
\qquad c>0,\quad D_t\geq0.
\]

分别证明 $D_t$ 表示什么、误差由何产生，以及是否可求和；不能把有限容差代码称为精确最小化。

## 逐级建立结论

| 结论 | 还需要的依据 |
| --- | --- |
| 目标单调 | 对实际每轮更新成立的一步不等式 |
| 目标值收敛 | 单调与有限下界，或适用的准单调收敛条件 |
| 改进量趋零 | 可求和下降、适当正系数和下界 |
| 聚点驻定 | 聚点存在、残差与驻定性联系、更新连续性或闭性等 |
| 全序列变量收敛 | 更强结构，例如唯一聚点或适用的 KL 分析 |
| 全局最优 | 问题结构与达到最优性的算法论证；凸性本身不够 |
| 唯一最优解 | 严格凸性或其他排除多解的结构，并先有存在性 |

上述列举是证明义务的方向，不是所有算法共享的充分条件集合。选定具体收敛定理后核对其全部条件。

## 有误差的望远镜求和

若上式对 $t=0,\ldots,T-1$ 成立且 $F\geq L$，则

\[
c\sum_{t=0}^{T-1}D_t\leq F(z^0)-L+
\sum_{t=0}^{T-1}\varepsilon_t.
\]

由此可以得到平均改进量或最小残差界；若误差总和有限，可进一步研究 $D_t\to0$。该结论本身没有证明 $z^t$ 收敛，也没有证明全局最优。

## 实现对应

记录初始化、投影、内层迭代、线搜索、随机样本和退出分支。小步长或相邻目标差很小，只是停止信号；若要用作最优性证书，应证明该信号如何控制残差或目标差。浮点误差使用明确误差模型，或把保证限定于理想算术。

复杂度同时保留外层次数、内层次数和求解精度。经验曲线可以检验实现是否出现预期行为，不能证明任意输入上的收敛。
