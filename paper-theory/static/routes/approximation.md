# 近似、稳定性与复杂度

## 指定误差作用的对象

区分矩阵误差、目标误差、梯度误差、解误差和最终任务误差。先证明相邻层之间的关系，再组合成完整结论。谱嵌入的稳定性往往还涉及相关谱隙；最终离散分配可能需要额外间隔条件。

## 一个可复用的目标误差传递命题

设 $f,g:S\to\mathbb R$，$x,y\in S$，在 $S$ 上有 $|f(z)-g(z)|\leq\varepsilon$，且 $g(x)\leq g(y)+\eta$。则

\[
f(x)\leq g(x)+\varepsilon
\leq g(y)+\eta+\varepsilon
\leq f(y)+\eta+2\varepsilon.
\]

通常取 $y$ 为原目标的最优点，但这需要先建立其存在性。该形式也允许任意比较点，避免无依据地引入 `argmin`。Lean 对应 `approximate_optimum_transfer`。

应用时分别证明一致近似界与优化误差界。仅在某个点近似准确，不足以控制另一个点；仅有训练目标误差，不足以得到测试精度。

## 近似算法与有限精度

解释低秩、采样、早停或浮点误差怎样进入 $\varepsilon$ 或 $\eta$。误差参数的取值应能由已有定理、可验证残差或明确假设支持。实际使用浮点数而形式化实数运算时，保证范围默认为理想算术；如需数值可靠性，应建立舍入误差模型或可检查证书。

## 复杂度的完整账目

记录输入规模、视图或模块数量、维度、秩、迭代次数、精度与存储对象。将总成本写为预处理、每轮内层与外层计算、预测或后处理的组合。指出哪些量在渐近分析中固定。

通信复杂度应区分消息次数、元素数量与字节数，说明数据类型。模型调用和 API 费用应按实际调用规则计入。线性运算复杂度不自动意味着线性实际耗时，若论文强调实际效率，应另有测量。

## 对实验的接口

从理论得到可检查的预测，例如误差随近似秩或内层容差变化。匹配实现与资源后再检验趋势。偏离预测时先查适用条件与误差估计，再决定修改方法、理论或结论范围。
