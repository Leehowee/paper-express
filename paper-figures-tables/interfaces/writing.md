# 写作调用与独立制作接口

入口是 [SKILL.md](../SKILL.md)，可由 [paper-writing](../../paper-writing/SKILL.md) 的 Introduction、Methods、Experiments 或 Appendix 调用，也可直接处理单张图、单个表格或整套图表。无需先完成整篇论文。

## 请求

复用写作方已有的研究问题、主张 ID、符号、方法、数据和版面信息，使用 [figure-brief.yaml](../assets/templates/figure-brief.yaml)。最小输入为：一个展示目的，以及足以确定图表内容的数据、方法描述或现有图表。缺少数据时返回结构及准确待补字段；不把附带合成数据当成用户结果。

| 调用方 | 主要内容 | 选择 |
| --- | --- | --- |
| Introduction | 现象、控制条件、问题定义及其证据范围 | F01；D01/D03；必要时 D06 |
| Methods | 输入输出、变量/公式、依赖、训练/推理、冻结/更新 | D01/D02；理论状态来自 paper-theory |
| Experiments | 原始重复、可比组、指标方向、组件与条件、成本、案例 | T01–T04；F04–F14；D04/D05 |
| Appendix | 扩展数据集、条件、参数、重复、案例与完整表头 | 相同模板，扩展面板/分表 |

`sources` 必须能定位真实文件及版本；`data_semantics` 定义统计单位、误差、单位、指标方向；`comparison_protocol` 定义哪些行可以排名。旧接口的 `measured_data` 可映射为 `measured`。理论保证必须带命题、条件和实际证明状态；图形只能显示其数学对象或已测现象，不能从曲线生成“已证明”状态。

## 执行

从 [目录](../assets/template-catalog.md) 选定配置，实际生成或修改图表，完成适用的数据、语义、视觉和可编辑性检查。沿用已有编号与术语；新增限制同步返回相关主张。对于会议，将决定性比较和关键失败留在正文，附录增加完整证据；对于期刊，增加必要深度，不机械扩充图表数量。

## 返回

使用 [figure-return.yaml](../assets/templates/figure-return.yaml) 返回文件、稳定标签、图注、正文衔接、源数据映射与限制。状态统一为：

- `layout_only`：仅内容结构，依赖的实测材料尚缺。
- `generated`：文件已生成，仍有检查待完成。
- `checked_with_limits`：所列检查完成，但有明确验证范围限制。
- `checked`：本次任务约定的检查完成；仍不等于科学主张被普遍证明。

检查分栏报告，不能以渲染成功替代数值核对，以原生对象存在替代编辑回存，或以案例好看替代代表性说明。工具不具备用户目标软件时如实记录实际使用的检查工具。

写作方核对数字、百分比/百分点、最优/并列、主文/附录标签和结论范围。图表源数据改变后重新生成相关表注与正文，不手工保持两个不一致版本。

跨模块的版本与状态可按 [共用上下文](../../shared/research-context.md) 记录。渲染审计中的代码、配置与数据散列用于识别生成版本；它们不替代语义和视觉检查。
