# Xi Peng 论文中的问题、方法与实验图表

本轮阅读范围及原文件见 [来源索引](source-index.md)。不同论文的图表承担不同职责，通用模板保留职责与比较逻辑，不照搬具体噪声假设、模块或参数。

## XP01：Partially View-aligned Clustering

**定位**：pp.3–4 Fig.1–2；pp.7–8 Table 1、Fig.3。

问题图从摄像头和时间信息解释“部分已对齐”的现实来源。方法图先给两路表示到聚类的总流程，再展开对齐模块，读者不用在一张图内理解所有细节。Table 1 按数据集和 ACC/F-measure/NMI 组织结果，但部分对齐与完全对齐方法可用的信息不同，不能只依据整表排序判断方法优劣。

Fig.3 同时检查 λ=0、参数范围、对齐比例以及训练过程。可迁移为四种独立问题：组件必要性、参数范围、条件稳健性、优化过程。新图采用实际数值间距；零值消融与正数对数扫描分开；目标和任务分数拆成对齐面板。对应 D02、T01、F04、F07、F09、F10。

## XP02：Learning with Noisy Correspondence

**定位**：p.2 Fig.1；p.4 Fig.2；p.8 Tables 1–2；p.10 Fig.3–4、Table 4。

引言把类别噪声和配对噪声放在同类图像/文本对象上说明，图中关系比抽象定义更容易理解。主图分出 warmup、划分、修正、交叉教学，并展开网络结构，强调“什么时候、用哪类样本更新哪部分”。

主表的层级包括噪声条件、数据集、检索方向和 R@k。正文说明 0% 噪声部分结果引用已有文献，而噪声实验多次运行报告最佳；提炼模板时必须保留来源区别，不能将最佳运行改写成均值±SD。通用代码要求真实逐次数据，并以均值/SD 或明确的其他口径重新设计，而不是默认复制这一报告策略。

分析图把干净与噪声样本的损失分布、拟合/修正后的分布并置；组件表解释 co-divide、rectify、warmup；案例呈现实际配对问题。通用化时统一分箱、密度归一化和样本集合，拟合曲线须来自真实拟合，不能凭形状绘制。对应 F05、T02、D04。

## XP03：Conditional Representation Learning

**定位**：p.2 Fig.1；p.5 Fig.2；p.7 Tables 1–2；p.9 Table 4、Fig.5；p.10 Fig.6；p.25 Table 5、Fig.8。

同一组对象在数量、类别、场景等不同标准下得到不同任务划分，由此解释“任务条件”改变表示用途。主图连接条件描述、语言生成的描述集合、文本基和图像表示投影；概念词与向量表示有不同语义，不能混画成同一种节点。

主结果按数据集、条件、shots 和指标分层，并比较基线及其加上 CRL 的版本。结果中的例外同样保留，不用统一改善叙述替代实际成绩。Table 4 的训练/未训练标记是协议说明；检索案例应固定查询条件和候选集。描述数量曲线回答投入增加后的饱和范围。t-SNE 展示应记录样本 ID、投影参数与拟合方式，视觉分离不替代下游定量评估。

可迁移为“同对象不同标准”的动机案例、基线与加模块的配对表、资源数量扫描和投影诊断。对应 D01、D02、T01、F07、F13、D04。

## XP04：Test-Time Degradation Adaptation

**定位**：p.1 Fig.1；p.4 Fig.2；p.6 Table 1、Fig.3；p.8 Table 4、Fig.5–6；p.9 Tables 5–6、Fig.7。另核对 p.3 的方法上下文。

Fig.1 并排展示经典、all-in-one、zero-shot 和 open-set 路线，比较的核心是训练/测试信息与适应位置。Fig.2 在总体扩散过程中展开 adapter 训练，冻结与可训练部分有明确符号。这类差异不宜压成“旧方法简单/新方法复杂”的装饰性比较。

主表用 PSNR/SSIM 表达恢复质量，方法按适用协议分组；经典方法在部分条件下更好，并不应删去。案例图保持相同输入和方法列，后续图进一步展开中间结果与采样过程。Table 4 的策略替换、Table 5 的组件去除、Table 6 的阶段边界扫描回答不同问题；两段边界不能当成一个普通参数解释。

对应 D01、D02、T01、T02、F07/F08、F14。模板要求明确恢复流程中的冻结/更新状态，展示中间状态时标明时间步或迭代，不用美化后的案例替代真实模型输出。

## XP05：Multi-Granularity Correspondence Learning（Norton）

**定位**：p.2 Fig.1；p.4 Fig.2；p.7 Tables 1–2；p.9 Table 7；p.20 Fig.3。

引言将真实视频帧、文本、时间位置和对应矩阵组合，说明粗粒度异步、无关内容和细粒度错配。方法图把细粒度到粗粒度的 OT 过程与吸收无关信息的 bucket 连起来，矩阵承担了具体的运算含义。

主结果区分去除/保留背景以及不同检索聚合策略。Table 7 的 A–J 变体同时包含组件、替代策略和参数，应提供可读字典，不能让读者猜字母。p.20 的匹配矩阵在同一帧/文本顺序下比较相似度、DTW、普通 OT 和 Norton，并保留无关文本的处理。共享色标使差异可比较。

对应 D03、D02、T01、T02、F06。通用化时保留虚拟节点、丢弃区或未匹配状态，不强迫所有对象都有一一对应。

## XP06：Dual-Level Noisy Correspondence（RULE）

**定位**：pp.2、4、7、9、23、31–32；Fig.1–2、4–5、7、11–15；Tables 1、3、7–8。

引言将噪声定义、受控观察和困难样本分成不同面板。主图包含不确定性/共识的可靠性分析、融合与差异学习，以及独立的测试时推理步骤，便于区分训练贡献和推理贡献。主表按 Inherent、20%、50% 等条件分块，再列多个数据集与 H@1/H@5/MRR；其中平均 H@1 不是对所有指标任意求平均。

分析包括散点、属性矩阵、λ/τ/β 扫描、损失组件和测试时策略消融。参数真实间隔与刻度要由新数据决定，不能把不等距数字当成等距连续变量。案例展示初始和最终候选排名：成功、排名恶化、歧义与缺失属性分别呈现。生成的推理文字是模型解释，需与已验证事实分开。

对应 F01、D02、T01、T02、F06、F07、D04。散点机制可用独立点的直接标签扩展 F13 的散点实现，但需另定义横纵变量，不能沿用“Projection”轴名冒充诊断量。

## XP07：Uncover Underlying Correspondence（CorreGen）

**定位**：pp.2、6、8–9、17–18、20；Fig.1–6、8；Tables 1、3–4。

引言使用同一实体集合比较 pairwise reweighting、realignment 与 correspondence generation，突出无法可靠对齐时不应强迫匹配的差别。主图通过 E-step、混合模型边际、虚拟样本和 M-step 解释生成与优化之间的依赖。训练阶段矩阵保持相同索引，读者能看到结构如何变化。

主表按 MR 条件、数据集、ACC/NMI/ARI 组织，原文报告五个种子的均值但未在该表逐格展示 SD；通用模板不能补造 SD。附录包含 CR 曲线、ρ 与其他参数的联合扫描、Sinkhorn 迭代、Virtual/Guide/InfoNCE 变体以及自然噪声图文例子。部分组件移除在干净条件下可有利，不能删除这一条件。MR、CR、CMR 的定义不同，不合并成一个“噪声率”。

对应 D01、D02、F06、T01、T02、F07、F08、F09。二维参数改用离散热力图时保留所有已测组合和失败单元，不插值出未经测量的最优区域。

## 对会议图表的归纳

正文优先保留定义问题、解释核心路线、支持主要效果和辨别关键机制的图表。附录承接完整设置、参数范围、额外数据集、更多种子和成功/失败案例，正文保留关键边界。表的分层应反映真实任务协议，方法图的分层应反映计算依赖；两者都服务于读者判断贡献，而非统一凑齐固定数量的图表。
