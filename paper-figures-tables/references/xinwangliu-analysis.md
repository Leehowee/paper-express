# Xinwang Liu TPAMI 论文中的结果与分析

按 [来源索引](source-index.md) 的本地版本和物理页序定位。本轮关注表头层级、比较单元、消融控制、机制解释、参数及过程图，不重做前一模块的理论证明审查。

## XL01：Efficient and Effective Regularized Incomplete Multi-View Clustering

**pp.10–11，Tables 2–3、Fig.6–7。** 主表汇集数据集与多个指标的均值和波动。消融比较仅初始先验、无先验以及正则化利用多个先验的方案，回答“先验如何进入目标”，并非简单的 Full 与 w/o。过程图检查迭代中的任务效果；参数图同时放入基线，显示正则强度存在范围效应。

迁移为 T01、T02、F10、F07：变体名对应精确定义，固定其他条件，区分先验来源与先验数量；参数曲线保留非单调区域。

## XL02：Multiple Kernel k-Means with Incomplete Kernels

**pp.11–12，Tables 5–6、Fig.6–8。** 内部补全质量和下游聚类效果分开评价，两者排序不必一致；缺失与噪声核分析给出受损条件，权重图帮助解释模型怎样处理不同核。原文讨论近似变体不能保证目标单调，实验停止行为不能补足这一保证。

迁移为 F06/F12 与 T01 的机制—任务配对，F09 的独立缺失模式重复，以及 F10 的过程图。保留实际重复单位；该处随机缺失模式的重复不能泛化成任意“10 次独立模型训练”。

## XL03：Absent Multiple Kernel Learning Algorithms

**p.8，Table 1。** 表格同时包含均值/标准差与相对最佳方法的成对检验信息。粗体关联“未在给定阈值下检测到差异”的统计规则，而不是只给数字最大者。原表阈值与注释需要一起读，p≥0.01 也不等于完成等效性检验。

通用 T01 默认仅标记数值最优，绝不凭字形猜测或复造原论文的显著性。若需要统计标记，额外说明检验单位、配对、假设、校正和阈值；没有原始重复数据时不计算。

## XL04：Communication-Efficient Federated Multi-view Clustering

**pp.10、13–14，Tables III、VIII–IX、Fig.3–5。** 主结果与带符号 Gap 共同呈现，负值保留。效果与通信代价的变化不总同向。过程分析同时涉及总目标、不同方向的子目标与任务指标，不能把它们笼统称为同一“收敛分数”。联合参数扫描区分耦合设置和独立设置。

迁移为 T01/T04、F10/F11、F08：保留成本范围、Gap 的基准和方向；双轴改为对齐面板；三维参数柱可改成有明确坐标的二维热力图。原文涉及网格中最佳结果的表述时，需要核对选择集，不将其默认为已经满足验证集选择规范。

## XL05：Contrastive Multi-View Kernel Learning

**pp.8–9、12–13，Tables III、VII–VIII、Fig.5。** 主表按核类型/视图进行传统核与学习核的配对；表内 `Avg` 是平均核构造，而不是平均性能。邻近讨论区分视图共性与异质性，小规模条件还可能出现退化，说明内部一致性不能无限强化。

学习率×归一化表保留优化失败；原文的 `-` 与 NaN/Inf 有对应原因，不能替成 0。分阶段目标曲线需标明切换点；未在当前阶段被优化的虚线量不应被解读为主目标。

迁移为配对 T01、含失败状态的 T03、阶段 F10，以及有下游控制的 F12。算法缩写、聚合名和指标名先建立字典。

## XL06：Hyperparameter-Free Localized Simple Multiple Kernel K-means

**pp.5、7–8，Fig.1–2、4–5。** 核权重与局部掩码权重配合任务结果解释设计；多初始点、多数据集的轨迹检查求解行为。曲线终值相近是实验现象，不能替代理论上全局最优的前提与证明。时间图的机器、内存和 MATLAB 版本属于比较口径的一部分。

迁移为 F12、T02、F10、T04：权重归一化与索引明确；重复初始化有真实 ID；时间显示原始单位或说明 log 轴，记录计时包含的计算步骤。

## XL07：Generalized Probabilistic Graphical Modeling

**pp.8、10–11，Table IV、Fig.2、4–7。** 主表的确定性结果、未完成结果和运行资源限制有专门符号。平均排名图使用 Friedman/Nemenyi 相关比较，不能将横线自动称为置信区间。机制图并列未处理图、噪声结构和处理后的图，部分面板的色标范围不同，读者必须注意数值含义。

剪枝、原型/标签策略与参数分析为解释提供不同控制。相对“对数运行时间”也不能转述为相同数值的速度提升倍率。

迁移为 T01 的缺失代码、F06 的色标说明、T02 的策略字典、F08/F11 的参数和成本。平均排名图只在先完成对应统计分析时另行绘制，本包不提供未经验证的 p 值或显著性连接线。

## XL08：SimpleMKKM

**pp.7–9，Tables 2–3、Fig.1–3。** 主表保留 OOM 和并非处处获胜的情况。论文同时改变目标和求解器，交叉消融因此能分离两种变化；只做“完整方法减组件”不足以回答归因问题。过程图比较不同求解器轨迹，任务指标可能与目标不同步。样本规模曲线的横轴是每类样本数，不是独立数据集个数。

迁移为 T02 的目标×求解器扩展、F10 的双面板、F09 的数据规模变体。不可运行的目标/求解器组合应说明数学或接口原因，不以缺失数值掩饰。

## XL09：Incomplete Multiple Kernel Alignment Maximization

**pp.7、9–11，Fig.1、4–5，Table 2。** 缺失率曲线组织多个数据集与指标，原实验使用多种随机缺失模式，比较应在模式层面匹配。迭代中的任务准确率存在波动，不能凭总体提高声称目标单调。核权重是内部诊断；聚合表的粗体定义也包含统计比较语义。

迁移为 F09、F10、F12、T01：报告独立缺失模式数、误差含义与实际统计规则；不能把运行曲线上的每个迭代点作为独立重复样本。

## 对期刊图表的归纳

期刊的额外篇幅可用于把“效果、原因、条件、代价”分开回答：主结果表给出协议下的精确比较，交叉或组件消融辨别来源，机制图配合可检验的解释，参数与稳健性确定已测边界，过程和效率揭示优化及资源行为。增加图表数量本身不增加证据；每张图应对应一个没有被已有图表回答的问题。
