# figures4papers 的继承与改编

本地实际文件名是 `figures4papers-main.zip`。快照摘要与已读文件逐项散列见 [upstream-manifest.json](upstream-manifest.json)。未以未核验的在线最新版本替换本地模板。

## 阅读与继承

阅读 README、LICENSE、`scientific-figure-making/SKILL.md` 及 api/design-theory/common-patterns，结合 VIGIL 消融代码、ImmunoStruct 柱图、RNAGenScape 速度比较、ophthal_review 组合图代码；视觉查看柱图、消融曲线、动机图与结构示意演示。继承克制的蓝/青/紫配色、清楚轴线、右上轴简化、紧凑面板、颜色之外的线型/标记编码以及矢量输出。

## 为本技能新增

| 原有思想 | 本次实现 |
| --- | --- |
| 面向具体论文的演示脚本 | CSV+JSON 驱动的 8 类绘图处理器，12 个就绪实例 |
| 统一图形风格 | 按物理毫米输出、最终尺寸字体、数据与视觉分别审计 |
| 实验结果的静态呈现 | 原始重复聚合、配对差、指标方向、并列与缺失状态 |
| 丰富的图形示例 | 动机/路线/机制/案例等 10 条按科学问题选择的路线 |
| 本地归档中没有 PPTX/SVG 源模板库 | 新建 6 套 SVG 示意、11 页原生 PPTX、4 类同源结果表 |

PPTX、D 类 SVG、原始数据接口和模板文案均为本次新制作，不能归为上游已经提供的文件。SVG 与 PPTX 的方法图通过同一结构定义生成，数值表通过同一聚合结果生成。

## 有意修正的做法

- 参数曲线用实际数值或明确 log 轴；零值单独处理。离散热力图注明已测组合。
- 柱形以零为基准，需要局部差异时使用点图；不用截断柱长夸大变化。
- 不把不同量纲指标相加求“总平均”，也不将最优运行换成均值±SD。
- 多方法表的排名限定比较块；原始报告口径、统计检验、引用结果和失败原因分别说明。
- 双轴过程图优先拆为对齐面板；机制图的整齐程度与因果证据分开。
- 不以巨大画布或缩字号处理拥挤，不把整张图片置入 PPTX 后称内部可编辑。

## 组织形式

继续沿用本项目 Nature 风格技能的组织：简短入口、manifest、共享核心、按任务加载的路线、可填写资产、按需来源分析。继承的是一般性指令与渐进加载，不把作者案例写成所有任务必须遵守的套路。前两部分的 [Nature 模板改编记录](../../paper-writing/references/nature-adaptation.md) 提供已有来源说明；本部分重点新增图表制作接口与资产。
