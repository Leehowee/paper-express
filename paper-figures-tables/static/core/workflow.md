# 基本原则与流程

图表的基本单位是一个可判断的问题。先写下“读者看完后应当知道什么”，再确定对照、坐标、分组与注释。一张复合图可以有多个面板，但面板应共同完成一个论证。

## 从材料到成品

1. **确定问题**。将“展示结果”具体化为效果、成因、条件、代价或边界。例如“增加预算后优势是否持续”，比“画一张折线图”更能决定展示范围。
2. **绑定材料**。记录数据文件、样本或日志编号；示意图记录方法段落、公式和模块定义。混合图逐面板标记证据类型。
3. **选择套路**。先确定比较关系，再从模板目录选布局。对照是否匹配、结果是否完整，优先于颜色和装饰。
4. **填充并生成**。数字由数据读取和聚合，标签由统一术语填充；代码、数据、图注共同保存。缺失信息保留 `[待补：内容]`，不以顺滑曲线或预设优势补齐。
5. **检查并修订**。分别核查统计口径、方法语义和最终尺寸；在实际渲染图上修复遮挡、误读和拥挤。
6. **回到主张**。给出证据直接支持的结论、仍需其他证据的解释，以及明确出现的例外。

## 一般性的版面安排

期刊可按“主结果—受控消融—机制证据—参数与边界—成本与案例”展开，必要时把大矩阵拆成多张图。会议正文保留决定核心判断的图表，附录承接完整条件、逐数据集结果和额外案例。正文图注必须说明比较条件；不能把决定公平性的说明仅藏在附录。

不是每篇论文都需要路线对比图、注意力图或 t-SNE。不能改变读者判断的图表可合并或省去。重复可用于核查，版面重复应有独立作用。

## 三种交付模式

- **初稿制作**：填写选定模板并输出实际文件、图注和简短正文解读。
- **润色重制**：保留数据含义，调整排序、尺度、布局和注释；对改变观感的轴范围或聚合方式作说明。
- **审查**：定位具体面板或单元格的问题，解释影响，提供可操作修改；可以修复的部分直接修复。

来源分析只用来选择结构。成品图注不需要叙述“某作者常这样画”，而应准确描述当前研究。
