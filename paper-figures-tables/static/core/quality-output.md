# 核查与返回

## 数据核查

从图表反查至少一个普通项、一个最优或并列项、一个不利项和一个缺失项。核对指标方向、聚合层级、n、误差定义、单位与比较范围。输入文件散列和生成配置随产物保存；记录是否使用了引用结果或预先聚合数据。

参数曲线保留真实顺序和间距；矩阵保留共同样本顺序；差值图核对配对 ID；效率图检查成本口径与所有额外模块。表格最优标记和图中排序由同一数据逻辑生成。

## 视觉与语义核查

逐张查看实际成品。在最终尺寸检查文本、图例、标记、误差范围、色标、面板顺序与黑白可辨性；不能只查看源码或低分辨率缩略图。流程图核对箭头方向、损失连接、训练/推理、冻结/更新和维度。留白应帮助阅读，不能挤压关键标签。

可编辑文件要保存、重新导入并验证代表性修改；至少修改一个标签和一个图形对象。原文件保持不变。用什么工具完成就报告什么工具，不把库的导入测试表述为 PowerPoint GUI 兼容性验证。

## 交付内容

1. 实际图表及图注；需要时给一句能直接放入正文的解读。
2. 代码、数据接口、配置或可编辑源文件。注明数据需重跑还是可以原生编辑。
3. 主张与证据范围：图表支持什么、哪些解释仍需验证。
4. 分开的数据检查、视觉检查与可编辑性状态，包含限制。

状态使用 `layout_only`、`generated`、`checked_with_limits`、`checked`；不要将“程序退出码为 0”直接等同于科学结论已验证。模板包的验证是资产与计算逻辑验证，来源论文的实验没有被复现。

首次生成后修复实际发现的问题。已有检查通过且未发生相关改动时，不重复运行无关检查。
