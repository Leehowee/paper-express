# 数据、比较与统计口径

## 最小必要信息

每个数值至少对应：数据集与划分、条件、方法或变体、指标定义与方向、单位、运行编号和结果状态。涉及误差项时，还要知道独立实验单位、重复次数和误差定义。已有汇总统计可以原样展示，但不得倒推出不存在的原始运行。

模板 CSV 的 `run` 是独立重复编号。交叉验证折、重复初始化、缺失模式、被试和单个样本不是可互换的独立单位。存在嵌套设计时，先按有效实验单位聚合或使用适当模型；不将相关样本当作独立重复增加 n。

## 聚合与缺失

默认模板计算算术均值及样本 SD（`ddof=1`）；SD 不是置信区间，也不是标准误。SD 至少需要两个独立运行。没有重复数据时设置 `uncertainty: none` 并如实说明。置信区间、显著性或多重比较应使用经过核查的统计方案，当前代码不自动推断它们。

`NR`、`OOM`、`timeout`、`error`、`NA` 分别表示未报告、内存失败、超时、运行错误和不适用。缺失项不填零。一个设置部分成功、部分失败时，同时报告成功率和条件统计，不静默丢弃失败运行。当前示例程序遇到混合状态会停止，要求先定义该报告方式。

不能直接平均不同量纲指标。跨数据集平均需说明是否等权、缺失值政策、纳入集合与聚合层级。“平均核产生的性能”也不等于“各核性能的平均”。

## 可比范围

在相同任务、划分、监督、输入、资源与选择协议内排序。额外标签、预训练数据、测试时推理或不同模型规模需要显式分组或列出。文献引用值与本地重跑值标明来源；最大值、均值、单次结果不能省略口径混排。

表格代码按声明的组、数据集和指标计算最佳项。默认在显示精度上保留并列；若采用未舍入数值排名，必须增加精度或说明并列外观。加粗表示数值最优，不表示显著性。未拒绝差异检验不能推出等效性。

差值必须注明方向和单位。百分比指标的绝对差是百分点；相对改善另算并注明分母。下降指标的最优方向由元数据决定，不能沿用准确率的排序。

## 配对、范围与图形变换

配对差值按相同 seed / fold / 样本 ID 对齐；不能用两组均值差的误差代替配对差的误差。缺少配对项时不得取隐含交集。

连续参数使用真实数值间距；跨数量级时用明确标注的对数轴。零值不能塞入对数轴。离散网格可以等距展示，但标明“tested values”，不暗示连续插值。缺测格保持空缺并注明原因。

条形长度从零起点编码。需要突出狭小差异时用点区间图。线图可放大范围，但显示完整刻度，不通过不同面板范围制造不存在的反转。矩阵比较使用固定样本顺序和可比色标；不同物理量可用各自色标并说明。

## 图像与案例

保留样本 ID、来源、原始图、输出版本与选择规则。同一案例各方法使用相同图像、区域和缩放；增强仅在各方法一致且披露时使用。热图记录归一化、层/头聚合和所取样本。真实失败、歧义和缺失条件是证据范围的一部分。

模型输出的解释和真实原因分开标记。注意力、嵌入分离、矩阵变清晰或单个成功案例只能支持相应的观察，机制判断还需要受控干预和任务结果。
