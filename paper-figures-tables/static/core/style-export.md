# 样式与导出

## 先锁定最终尺寸

示例提供 180 mm 宽的组合图及 100–115 mm 的单图，字体通常 7–8 pt。这是模板的设计配置，不是 Nature、TPAMI 或某会议的官方要求。正式稿件按目标年份、阶段和版式的官方说明配置宽高、字体和格式。

在最终插入尺寸检查标签、误差条、连线和表格密度。大画布上的“大字”缩入正文后仍可能无法阅读。程序固定物理尺寸导出，不用自动裁边改变声明宽高。

## 统一视觉语义

继承 figures4papers 的克制配色、清楚轴线、紧凑多面板和矢量输出。深蓝 `#0F4D92` 可用于焦点方法，青色 `#42949E`、紫色 `#9A4D8E` 和灰色用于稳定区分；同一方法跨图保持同色。颜色同时配合标记、线型、纹理或直接标签。

只突出承担当前比较的对象。不默认把本文所有条形染成最亮颜色，也不将对手画得更小、更模糊或流程更混乱。数据多时优先分面，避免十几种颜色和重复图例占满绘图区。

## 可编辑性的层次

- Matplotlib SVG 保留普通文字、路径和图形，适合矢量编辑；公式的部分字形可能由数学字体表示。调整数据时应重新运行代码。
- D01–D04、D06 的 SVG 与 PPTX 来自同一份 `diagram-scenes.json`；D05 来自构建脚本中的共享行列定义。节点、标签和箭头分别存在，便于编辑。
- PPTX 第 1–4、11 页为原生形状、文字与连接线，第 5–9 页为原生表格，第 10 页为原生图表及嵌入数据工作簿。公式占位采用可编辑文本，不声称是原生数学公式对象。
- 把完整 PNG 或 SVG 放进 PPTX 只能证明图片可以移动，不能证明内部组件可编辑。

## 输出选择

数值图默认导出 SVG、PDF 和 300 dpi PNG；SVG/PDF 用于论文插图，PNG 用于预览。照片保持原始分辨率；SVG 内的案例照片仍为栅格。LaTeX 表格提供 `booktabs` 三线结构，必要时分块或拆表，避免全表缩小到不可读。

模板库中的示意图通过概念参考后重建为原生对象。用于真实投稿时依据该目的地政策决定是否采用这类设计，并保留必要说明；不能用生成图像替代实测曲线、真实样本或实验输出。
