# 稳健性与条件变化

用完整条件范围描述性能如何变化。噪声、缺失、错配、腐蚀、规模和领域迁移是不同因素，各自定义分母与生成机制；不能统称为一个含混的“难度”。

## 套路：条件 × 方法，数据集或第二因素分面

使用 F09。横轴是一项有序条件，颜色和标记对应方法；第二因素优先分面，或使用有明确定义的线型。保持同一方法跨面板的编码。每个条件有独立生成的缺失模式时，误差反映这些模式；同一数据上多次随机初始化的误差反映另一种不确定性。

引言可选最能说明问题的诊断条件，实验正文补齐核心范围，附录展示完整数据集。范围或样本数变化须注明。对性能跌到失效的部分保留数据，不把超时或 OOM 画成零。

填写：`{{因素定义}}、{{取值范围}}、{{每条件重复单位}}、{{保持不变的训练/选择协议}}、{{评价指标}}、{{额外因素}}`。
