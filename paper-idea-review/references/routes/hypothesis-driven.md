# 假说与反常现象驱动

假说驱动研究检验某种解释是否成立；反常现象驱动研究先确认观察的可靠性，再寻找能够解释该观察的关系。两者都需要能够区分主要竞争解释的证据。

## 论证逻辑

`现象或既有认识 → 候选解释 → 明确假说 → 差异预测 → 判别检验 → 替代解释 → 有限度的结论`

经验事实与对事实的解释分别成立。已有成功可以成为研究起点，其成因、条件或含义仍需独立检验。

## 形成研究问题

1. **明确待解释的事实。** 说明观察来自何种对象与条件，以及已有证据的可靠程度。
2. **将解释写成假说。** 限定对象、条件和关系，使其具有可识别的支持与否定条件。
3. **提出竞争解释。** 选择能够解释现象且具有实质差别的候选解释，避免人为制造简单对立。
4. **导出差异预测。** 明确不同解释在何种条件下对哪些观察量作出不同预测。
5. **设计判别检验。** 选择足以区分解释的评价和对照，并检查主要混杂因素。

对于反常现象，首先检查重复性、数据处理、实现、指标和样本选择。现象尚不稳定时，优先完善观察依据。

## 审查重点

- **创新性**：待检验解释是否真实存在，已有研究是否已完成相同区分，当前工作新增了什么认识。
- **重要性**：解释成立或被否定，将如何改变理论理解、方法选择或资源投入。
- **可行性**：不同解释是否可被现有观测或干预区分，所需样本、材料与检验精度是否可获得。

选择指标的依据应是其判别能力。平均结果、分布变化、个体差异和条件差异可承担不同的解释任务，按问题需要使用。

## 验证与优化

建立紧凑的比较：

`候选解释 → 具体预测 → 判别条件 → 关键观察 → 混杂因素 → 否定条件`

在检验前明确结果的解释方式。必要时使用具有已知效应的对照，检查评价是否有能力检测目标差异。

根据证据强度形成结论：

- 能区分主要解释的结果，可以支持有范围的解释选择。
- 与假说一致但缺乏判别力的结果，应作为相容证据表述。
- 不同条件下的结果不一致时，检查假设的适用范围与异质性。
- 有限观察中未发现效应时，说明检验范围、精度与剩余不确定性。

假说被否定后，仍应评估是否形成新的边界、解释或研究方向。研究价值不以原假说得到肯定为前提。

## 问题表述

> 〔现象〕可以由〔候选解释〕说明，但现有证据尚不能确定〔关键分歧〕。不同解释在〔条件〕下对〔观察量〕给出不同预测。拟通过〔关键检验〕区分它们，并检查〔主要替代因素〕。

最终形成明确假说、竞争解释、差异预测、关键检验和结果解释边界。
