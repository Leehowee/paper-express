# 机制驱动

机制驱动研究解释结果如何产生，并通过对关键过程的干预检验解释。机制主张需要连接可观察过程、可实施干预与目标结果。

## 论证逻辑

`可靠现象 → 候选机制 → 可测过程 → 选择性干预 → 结果变化 → 替代解释控制 → 机制边界`

方案有效与机制解释成立分别评价。性能变化可以说明方法作用，机制归因还需要识别产生该作用的过程及条件。

## 形成研究问题

1. **确定待解释现象。** 说明现象的稳定性、发生条件与研究价值。
2. **建立机制关系。** 用 `干预 X → 中间过程 M → 结果 Y` 表达候选关系，标明已有依据和待验证环节。
3. **选择观察量。** 说明测量如何反映目标机制，以及代理量与实际过程之间的差距。
4. **设计有针对性的干预。** 预测中间过程和结果应如何变化，并指出机制不应发挥作用的条件。
5. **处理替代解释。** 区分目标机制与资源、容量、优化过程、额外信息及配套设计的影响。

概念类比应落实为明确的作用对象和可检验关系。名称或直观图示本身不足以建立机制解释。

## 审查重点

- **创新性**：是否识别了新的机制关系、必要条件或作用边界；候选设计是否已被现有机制解释覆盖。
- **重要性**：机制是否解释有价值的现象，是否能支持可迁移的认识或设计原则。
- **可行性**：中间过程能否测量，目标因素能否干预，关键替代解释能否控制。

根据主张选择必要的检查：

| 检查 | 判断要求 |
| --- | --- |
| 可观察性 | 诊断量与所声称机制之间有明确联系 |
| 干预特异性 | 能识别干预同时改变了哪些因素 |
| 必要性 | 移除或削弱机制后，目标能力是否按预测变化 |
| 充分性 | 引入机制是否足以产生效果，或仍依赖其他条件 |
| 强度关系 | 干预强度与过程、结果之间是否具有可解释关系 |
| 适用边界 | 在机制不应重要的条件下，结果是否符合预期 |

必要性与充分性分别判断；组件的独立贡献与交互作用分别解释。

## 验证与优化

优先采用能够观察中间过程的诊断任务，同时记录干预前后的过程变化与结果变化。根据主要替代解释设计匹配对照，必要时采用交叉组合比较。

组件移除可能同时改变优化稳定性、信息流或资源投入。解释消融结果时，明确这些变化对归因的影响。

当方法收益可靠而机制证据不足时，收敛机制措辞，并提出更有针对性的检验。相关性、可视化与个案可提供线索，其结论范围由实际证据决定。

## 问题表述

> 在〔条件〕下，〔现象〕伴随〔可测过程〕的变化。拟检验〔机制关系〕是否参与产生该结果，通过〔干预〕并控制〔替代因素〕，考察〔中间过程〕与〔结果〕是否按预测变化，以及该关系在哪些条件下失效。

最终形成机制关系、观察与干预方案、主要替代解释及可支持的归因范围。
