# GH-A：AdaptiveNN 如何组织框架问题与理论支撑

论文：*Emulating Human-like Adaptive Vision for Efficient and Flexible Machine Visual Perception*。本地为 95 页预印本，正式发表信息见 [来源索引](../source-index.md)。以下均引用本地版本，不能将其页码或措辞视为正式期刊排版。

## 核心判断

文章把分散的效率困难组织成一个共有问题：高分辨率输入、大模型与资源要求之间的张力；然后将被动处理整个场景的方式视为一个可改变的共同条件。提出的框架要同时决定观察位置、累积表征和停止时机，并解释如何训练这些连续与离散组件。[PDF pp.2–10]

这是框架驱动与问题驱动结合、理论支撑设计的范例。原文不提供作者实际先想到理论还是先做实验的时间线。

## 问题叙述的推进

1. **承认已有进展及其代价**：表征学习和规模扩展带来能力，也增加部署的资源要求。[p.2]
2. **寻找共同处理假设**：全图或全视频输入被一次性处理，使高分辨率与高容量模型的组合昂贵。[pp.2–3，Fig.1]
3. **用类比提出可操作改变**：人类视觉的启发被转写为局部注视、顺序整合和适时停止。[pp.3–4、7–8]
4. **准确承认前人**：已有 recurrent attention、动态网络和自适应方法；作者指出它们在组合适应性、扩展性、任务范围和学习原则上的不足，而不是声称从无人研究主动视觉。[p.4；图像型补充 pp.44–47]
5. **把框架要求写完整**：跨骨干、跨任务、无需额外注视位置监督，以及可按预算调整。[pp.4–10]
6. **为不同价值主张安排不同证据**：效率、任务与预算适应、人类行为比较、组件控制分别检验。[pp.12–20]

**本技能重构的问题**：在保持强表征模型能力的同时，能否以任务驱动的局部顺序观察替代全场景处理，形成兼容不同视觉任务、能够联合学习且按预算调整的感知框架？

## 理论承担的真实工作

Theorem 1 对依赖参数的采样分布下的期望任务损失求导，得到表征学习与策略梯度两部分，从而解释离散注视选择为什么能与常规表征学习协同训练。[pp.9–10；证明 pp.22–23]

以下是理解该分解的**自拟二状态例子**，不是论文实验：

设 $L(\theta)=p(\theta)\ell_1(\theta)+(1-p(\theta))\ell_2(\theta)$，则

$$L'(\theta)=p\ell_1'+(1-p)\ell_2'+p'(\ell_1-\ell_2).$$

若当前 $p=0.4$、$p'=0.1$、$\ell_1=1$、$\ell_2=3$、$\ell_1'=2$、$\ell_2'=0$，则导数为 $0.8-0.2=0.6$。把选择分布误当常数只得到 $0.8$，漏掉“改变观察选择”的影响。

可迁移原则：理论需要对建模或算法有实际作用。不过，通用求导恒等式本身不是自动成立的新颖性证据；需比较具体建模与已有学习规则。

还应区分原始分解与实际训练：p.10 将折扣因子和差分奖励作为增强后的学习规则；这不是仅凭梯度恒等式就证明全局收敛或任务性能优越。推导还需要常规可微性、期望与微分交换等条件审查；本次未对其进行 Lean 证明。

## 需要保留的边界

- “不可能三角”是解释性问题框架，不是原文证明的数学不可能性定理。[pp.2–3]
- 最多约 28 倍对应道路图像交通标志任务中 FLOPs 的特定比较，不等于所有任务的实测延迟或能耗都改善 28 倍。[p.13；p.23 指标口径]
- 固定 patch 大小的优势不能独自证明总成本永远与场景尺寸无关：还要考虑初始观察、决策开销及为维持质量所需的观察次数。这是本次分析提出的检查条件。
- “human-like”由特定行为测量支持；难以辨别或未发现显著差异，不自动证明认知机制等同、严格统计等价或不存在先天偏置。[pp.17、19、21、26]
- p.8 说阈值在 validation data 上求解，p.27 具体实例化为 training set。应保留这一表述差别，追溯数据划分；仅凭这两句不能判定测试泄漏。
