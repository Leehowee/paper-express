# GH-D：Differential Transformer 如何把观察变成机制设计

论文：*Differential Transformer*，本地文件标明 ICLR 2025。见 [来源索引](../source-index.md)。

## 核心问题的形成

引言从上下文检索困难进入，利用答案位置与无关上下文的注意力分配说明一种内部失败现象，再将无关区域获得的非忽略权重称为 attention noise。这里建立了任务失败与可测内部量之间的联系。[PDF p.1，Fig.1]

**本技能重构的问题**：在需要从干扰上下文提取信息时，能否通过改变注意力分配机制抑制无关信号，并改善上下文利用，而不将收益混同于模型规模或其他配套设计？

## 从概念到可执行设计

作者以差分放大器和降噪为类比，提出两个 softmax 注意力图相减，并用可学习系数控制第二项。类比落到明确算子，而不是停留在名称层面。[pp.2–3，Eq.1–3]

理解该算子的**自拟例子**：若两个注意力向量分别为 $(0.6,0.4)$ 与 $(0.2,0.8)$，取 $\lambda=0.5$，差分得到 $(0.5,0)$，第二个位置的贡献被抵消。它展示一种可能的抵消效果；实际学习是否形成这种配合仍要验证。差分权重可以为负，也不必总和为 1，不能沿用普通概率权重的全部直觉。

## 如何让实验服务机制

| 证据 | 所回答的问题 |
| --- | --- |
| 多 needle、位置和长度变化，pp.6–7 | 干扰变多或目标处于不同位置时，检索行为如何变化？ |
| 答案与噪声位置的注意力分配，Table 3，p.7 | 是否观察到所提出的内部变化？ |
| GroupNorm、头数和初始化消融，Table 6，p.10 | 增益能否由其他配置解释，配套设计是否必要？ |
| 归一化后的激活与量化结果，p.9 | 该设计还带来哪些可独立测量的性质？ |
| 同设置训练的 Transformer，Appendix B，p.16 | 是否有可用于归因的匹配基线？ |

Table 6 的细节尤其重要：普通 Transformer 加 GroupNorm 并未获得相同增益，而 DIFF 删除 GroupNorm 会变差。由此应区分“单独带来增益”与“使另一机制稳定工作的必要配套”，避免把消融机械解释为组件排名。

## 边界与可迁移规则

- 热图和最终性能一致变化可支持机制解释，但并不穷尽所有因果替代解释。
- p.9 对幻觉改善的原因使用可能性解释，应保留这种强度。
- 同参数或近似 FLOPs 不等于完全相同的硬件吞吐；理论计算量、实际实现和应用表现应分别报告。
- 数学推理扩展包含额外数据训练和蒸馏阶段，不能将这部分效果直接当作原始架构无额外训练的能力。[p.16]

采用 [机制驱动路径](../routes/mechanism-driven.md)。可学到的顺序是：具体失败 → 内部诊断 → 干预算子 → 诊断性任务 → 配套条件与替代解释检查。以上是论证结构归纳，不是作者研发时间线。
