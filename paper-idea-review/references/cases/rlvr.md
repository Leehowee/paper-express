# GH-R：RLVR 论文如何把广泛信念转成可检验问题

论文：*Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?*。NeurIPS 2025，奖项准确名称为 Best Paper Runner-Up，见 [来源索引](../source-index.md)。以下页码为本地会议 PDF 页序。

## 核心判断

文章的贡献组织围绕一个解释性问题：RLVR 的平均表现增益，究竟来自更有效地抽取已有正确路径，还是获得了超出起始模型的新推理能力。它允许“技术有效”与“关于技术为何有效的解释不足”同时成立。[PDF pp.1–4]

## 问题叙述的推进

| 环节 | 原文做法 | 研究作用 |
| --- | --- | --- |
| 承认经验成功 | RLVR 在推理任务中有效 | 建立共同事实，避免稻草人；pp.1–2 |
| 揭示解释跳跃 | 从传统 RL 发现新策略，类比到 LLM 获得新推理能力 | 把现有信念提成可质疑对象；p.2 |
| 明确竞争解释 | 新能力，还是基座已有路径的重新分配 | 使问题拥有不同可观察答案；p.2 |
| 重新选择诊断量 | 从平均表现扩展到 pass@k 和问题覆盖 | 常用指标不足以独自区分解释；pp.2、4 |
| 排除简单反驳 | CoT 检查、问题集合、PPL、算法和熵等分析 | 避免只凭一条曲线下结论；pp.6–9、19、22–23 |
| 留下后续方向 | 讨论探索与多轮环境交互 | 负结果生成下一步问题，而不是断言 RL 永无潜力；pp.10、17 |

**本技能重构的问题**：在匹配的评估设置和有限采样预算内，当前 RLVR 是否使模型解决更多基座模型难以覆盖的问题，还是主要提高了已有可解问题的成功采样概率？

## 为什么指标的变化具有研究意义

pass@1 主要反映单次成功概率，pass@k 则考察给定尝试次数内至少一次成功。它是对覆盖问题的操作性度量，不等于现实中能自动选出正确答案，也不等于无限预算的能力上界。[pp.4–5]

以下是**自拟例子**：A 在一半问题上每次以 0.5 概率成功，另一半永不成功；B 在所有问题上每次以 0.1 概率成功。两者 pass@1 分别为 0.25 与 0.10。在独立采样假设下，pass@8 分别为 $0.5(1-0.5^8)\approx0.498$ 与 $1-0.9^8\approx0.570$。单次更强和有限预算下覆盖更广可以指向不同模型。

原文使用无偏估计式 $1-\binom{n-c}{k}/\binom{n}{k}$，其中 $n$ 为生成数，$c$ 为正确数，$k\le n$；各任务的最大采样数不同。[Appendix A.2，p.16]

## 主张与检验的对应

- **现象是否稳定**：多个模型、大小、数学、代码与视觉推理任务的 pass@k 曲线。[pp.4–7]
- **是否只改变概率而非覆盖**：逐题准确率分布，以及基座独有、RL 独有、共同成功和共同失败的问题集合。[p.7，Table 2；p.22]
- **是否靠猜答案**：检查部分困难数学题的正确 CoT，辅以代码任务与过滤后的 AIME 分析。[p.6；p.19]
- **轨迹是否与基座分布接近**：对生成路径进行 PPL 分析；这是概率层面的支持，不是枚举了全部推理机制。[pp.7–8、21]
- **指标是否能显出其他训练方式的差异**：加入蒸馏模型比较。[p.8，Fig.7]
- **现象是否完全由实现选择解释**：统一框架比较六类 RL 方法，以及训练步数、rollout、KL 和匹配输出熵的分析。[pp.8–9、22–23]

Fig.1 左侧是解释图，右侧是训练设置中的曲线。要分别标记其证据身份，不能把示意树当作完整枚举的真实解空间。[p.2]

## 需要保留的边界

1. 核心证据是被研究模型、任务、训练和采样设置中的经验结果；不存在针对所有 RL 算法或未来规模的普遍不可能性证明。[pp.9–10、17]
2. 有限采样中没有成功，不能证明成功概率为零。PPL 较低也不能独自证明不存在新机制；需要保留概率代理与能力概念之间的距离。
3. Table 2 的 MATH500 在 $k=128$ 时仍有 1% 的 RL 独有成功题；Appendix D.7 说明基座在增至 1,024 次后也解出。表述应保留采样预算，不能抹掉局部例外。[pp.7、22]
4. 增大 rollout 的实验因成本仅训练 220 步，原文说明尚未收敛。因此不能将其直接读作充分扩展训练后仍无效的证据。[p.22]
5. 数学采用 zero-RL；编码和视觉推理的起点不完全相同。归因研究需要始终对齐每个 RL 模型自己的起点。[p.3]

## 转化为技能

采用 [假说与反常现象路径](../routes/hypothesis-driven.md)。先把成功与解释分开，再让竞争解释对可观察结果作出不同预测；检验有用的反例和替代解释，最后把结论限定到已检验范围。

对用户 idea 的优化可以是改进评估、识别边界或推翻解释，不要求每次提出一个新模型。奖项说明其获得认可；科学判断仍依靠可定位的证据。
