# 共同审查标准

适用于所有研究路径。以研究问题、证据和适用条件组织判断，根据任务规模确定分析深度。

## 证据先于评价

区分材料提供了什么、研究者如何解释，以及仍需检验什么。引用靠近其支持的判断，重要结论保留可核查的来源或数据位置。

| 证据状态 | 表述要求 |
| --- | --- |
| 已提供材料 | 说明其中可观察的结果及条件，检查其是否支持当前判断 |
| 文献作者主张 | 归属于相应来源，区分测量、解释与外推 |
| 已核实事实 | 指明核查来源、对象和范围 |
| 分析推断 | 说明推理依据、必要前提和替代解释 |
| 待检验假设 | 给出预测、验证方式及可能的反证 |

同一材料可能同时包含不同证据状态。首创声明、机制解释和普遍性主张需要各自的支持，不能继承其他结果的可信度。

## 问题应指向具体未知

将研究缺口表述为尚不清楚的关系、条件、原因或边界。说明已有工作确立了什么，以及当前问题从哪里开始。

用研究对象、适用条件和判断标准限定核心概念。操作性指标应能回答目标问题，并说明它尚未覆盖的含义。

| 判断层次 | 审查重点 |
| --- | --- |
| 指标与目标概念 | 评价量测量了什么，能否承接能力或性质的主张 |
| 局部结果与整体效用 | 局部改进是否影响最终目标，环节间是否存在依赖或代价转移 |
| 观测关联与因果机制 | 结果是否排除了主要替代解释，是否需要直接干预 |
| 有限观察与一般结论 | 样本、条件和验证范围能支持多大的外推 |
| 数学对象与实际实现 | 假设、近似与实现变化是否影响理论结论的适用性 |
| 资源指标与实际成本 | 成本口径是否完整，代理量与实际运行代价是否一致 |

研究问题与候选方案分开评价。问题有价值并不保证某个方案有效；方案有效也需要说明它回答了哪个问题。

## 创新性体现为实质性的知识增量

明确当前研究相对最接近工作的变化，再判断变化是否产生新的认识或能力。创新可以体现为新问题、新条件、机制识别、理论推进、评价区分或约束下的新能力。

建立文献比较时：

1. 按问题、关键假设、机制或数学对象检索，并检查相邻领域的等价表述与后续研究。
2. 优先读取原始论文和官方档案，核对版本、实际结论与适用条件。
3. 比较真正接近的工作，说明已有贡献、当前差异及差异的价值。
4. 记录检索日期、关键查询和覆盖限制；无法完成核查时继续分析问题逻辑，并明确新颖性尚待确认。

需要时使用比较表：

`工作与来源 → 已解决内容 → 条件与假设 → 当前差异 → 差异价值 → 待核查事项`

结论应能区分“已有工作直接覆盖”“可能存在实质差异”“当前差异不足”和“核查尚不完整”。名称变化、组件组合与评价场景变化，需要通过其新增内容说明贡献。

## 重要性取决于答案能够改变什么

说明研究答案对知识、决策或能力的影响，并限定受影响的对象与条件。学术价值和实际效用可分别成立，无需强行赋予同样的权重。

重点判断：

- 回答该问题后，哪项认识、设计选择或实际能力会发生变化。
- 假说被否定时，是否仍能排除解释、揭示边界或纠正研究方向。
- 获得的结果是否真正回答了问题，还是仅改善了一个相关指标。

背景的重要性应落实到具体未知及其后果。理论工作可通过澄清条件、改进界限、揭示结构或建立不可能性结果体现价值；经验研究也可通过可靠的负结果和边界分析形成贡献。

## 可行性包括可回答性与可执行性

首先判断所需证据能否区分候选解释，再判断获取证据的条件是否具备。

- **材料基础**：数据、基线、观测量、数学定义和必要前提是否可获得，独立样本及重复测量单位是否明确。
- **比较条件**：目标因素能否与额外信息、模型容量、训练过程、调参与资源投入区分。
- **验证能力**：评价、干预或证明是否足以支持目标结论，关键假设是否能够检查。
- **资源约束**：数据、计算、人工和证明工作是否可承受；估算说明依据和不确定性。
- **主要风险**：最可能的失败环节是什么，失败后能否据此调整问题或方案。

系统效果比较与机制归因具有不同要求。允许方案展示实际能力，同时为归因主张设计必要的匹配对照。

先导验证应优先处理决定研究能否成立的关键未知。证据精度不足或检验能力有限时，保留不确定结论，并说明继续判断所需的条件。

## 改进建议应改变研究判断

在证据允许的范围内形成最有依据的问题版本，再评估关键反对意见。每项建议说明它完善了哪个判断，以及什么结果会改变后续选择。

| 建议 | 适用条件 | 后续重点 |
| --- | --- | --- |
| 推进 | 问题明确，差异有依据，验证条件具备 | 完成关键实验或证明 |
| 先验证 | 核心现象、假设或比较基础尚未确立 | 获得最有判别力的证据 |
| 收窄 | 已有支持局限于部分对象或条件 | 调整问题范围与结论强度 |
| 改路线 | 当前方案不足以回答问题，存在更合理的证据路径 | 修改建模、方法或验证设计 |
| 暂缓 | 关键前提不成立或必要资源不可获得 | 说明重新评估所需的条件 |

综合判断应保留创新性、重要性与可行性的分别论证。避免以平均得分消解关键障碍，也避免将证据缺失直接判为假说错误。
